# QA test plan: Fish

Written before testing. Every row is checked by a command f-qa runs itself, inside a baton slot from f-producer (or Editor-free, on files, where noted). Numbers from other agents are "claimed" until qa reproduces them. **Every target number is read from the research brief and the recorded `studio:decisions` / `studio:design` records at test time, never typed into a test or this plan.** Where the brief gives a range, the range is the bar; where it gives a point, ±25% (F3) or the brief's own tolerance applies.

## Ground rules

- **Baton:** only in an f-producer grant; reply "started" at once; `unity status` first (someone's batchmode run may show); before any eval confirm `Application.isBatchMode == false` and `EditorApplication.isPlaying == false`; release with what changed and what is verified. qa probe code is staged in the scratchpad (`fqa/`), offline-compiled, and landed only inside the slot, under `Assets/Tests/` and removed or kept per f-td.
- **Snapshot binding:** each result names the state it ran against: `git status --short` on `fish-pod` (LFS filters off, PNG noise ignored) plus SHA-256 of `World.unity`, `MapConfig.asset`, `WaterMaps.png`, the fish settings/tuning asset(s), every fish prefab and material, and the build output.
- **Pre-gate baseline (taken 2026-10-07T19:27:09Z, before PHASE 1 OPEN):** git status shows only the untracked spec (plus LFS-filter PNG noise in `water-look/flat/`, no content change); 0 fish files under Assets/; build list = `Assets/Scenes/World.unity` only. SHA-256 list of 1,353 .cs/.unity/.asset/.json/.shader/.hlsl/.mat/.prefab/.asmdef/.fbx/.py/.meta files under Assets/, Packages/, ProjectSettings/, tools/ in the scratchpad (`fqa/pregate-baseline.sha256`).
- **Flaky = fail:** gating suites run 3x under the fixtures' pinned `Time.captureFramerate = 60`; all 3 must pass. Exception: the wildlife walk, graded under the W-QA-1 rule in F10.
- **Fish RNG isolation (requested of f-engineer up front):** fish code uses its own seeded `System.Random` (or a hash), never `UnityEngine.Random`, `Time.timeScale` or shared statics that birds/wildlife read. Otherwise adding fish shifts the bird (42/60/78 exact) and wildlife baselines and F10 can't tell a regression from a reseed. qa greps for it.
- **Fish on/off switch for tests (requested of f-engineer):** a fixture-level way to disable the fish system in the same Editor session (component disable or a test hook, not a code edit), so F10 can run birds/wildlife fish-off and fish-on back to back.
- **Player windows:** no player launch or visible game window without team-lead's OK. qa sends f-producer the exact command; f-producer asks team-lead. `Get-Process WashedAshorePOC` must be empty first; foreground launch, `-monitor 1`, wait on the PID separately.
- **Web:** built with deploy-web.ps1's build step only (the W10 `unity build ... WebGL.asset --output-path Builds\Web` command). No Cloudflare/R2 deploy. Web FPS needs Noah at the PC, window visible, team-lead driving Chrome.
- **Known terrain caveat (water-td-note §4.1):** `TerrainQuery.Height` falls back to the nearest edge where there is no tile. Fish code must use `TryGroundHeight` only (f-engineer agreed: no tile = land). qa greps fish code for `TerrainQuery.Height(` and cross-checks bed values against the terrain asset height near tile boundaries.
- **f-td `gate/fish-technique-addendum-1` (rev 1.2, binding):** there is no runtime tile streaming (all 20 tiles are baked), so F9 is graded on the addendum's reading. C# sources of record: bed = `TerrainQuery.TryGroundHeight` (exact, unclamped); shore distance (`BellsBendLevelMaps.ShoreDistance`) was named here, but f-td's later `ruling/fish-depth-bands` removes it from the fish plan (it measures to the inner bank, wrong near Robertson Island and the opposite bank): bands are by bed depth only and land = `TryGroundHeight` false or terrain ≥ W; surface = `WaterBody.Active.SurfaceY(x, z)` (WaterLevelY + WaterMotion.Offset at WaterClock.Now). WaterMaps is GPU-only and must not be made CPU-readable for fish (qa checks its import settings stay non-readable). Shader cull of record: (1 − F) × Tavg < 0.02 ⇒ not drawn; one implementation (`ruling/fish-cull-function-home`): a pure static function over a FishMurk struct filled from the water material, depth = surfaceY − (centre y + half body height), depth ≤ 0 drawable. qa re-implements it from the water material's values and compares it with the dumped draw mode per sample. Spawn-rule "not drawable" = culled OR beyond draw distance OR outside the frustum padded by one body length. Facing fix: `"face"` appended as the last `HeadNames` entry, Version not bumped.
