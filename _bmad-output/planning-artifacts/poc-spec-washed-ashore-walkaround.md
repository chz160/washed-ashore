# POC Spec: Washed Ashore walk-around

**The question this answers:** can Ruflo's studio agents take an empty folder to a Unity 6.6 project you can walk around in, using only the `unity` CLI, with no person editing the project?

**This is a feasibility spike, not a vertical slice.** A FAIL with a clear reason is a valid result.

## Fixed inputs (not up for debate)

| Item | Value |
|---|---|
| Project path | `E:\GitHub\washed-ashore` |
| Editor | Unity `6000.6.4f1`, URP |
| Control surface | `unity` CLI 1.0.0-beta.12 + `com.unity.pipeline`. No third-party MCP. |
| Terrain | Generated by script (`TerrainData.SetHeights`), with ground textures from ambientCG (CC0) via API |
| Plants | Quaternius Stylized Nature MegaKit (CC0) from `vendor/` |
| Animals (stretch goal) | Quaternius Ultimate Animated Animal Pack (CC0) from `vendor/` + `com.unity.ai.navigation` |
| Controller | Hand-written CharacterController + `com.unity.inputsystem` |
| Banned | Unity Asset Store packages, Starter Assets, paid assets, assets that aren't CC0 |

## What a person is allowed to do

1. **Noah drops the two Quaternius zips into `E:\GitHub\washed-ashore\vendor\`** before kickoff. This is the only manual step, because itch.io has no download URL a script can use.
2. **Noah approves permission prompts** when they appear.
3. Nothing else. **Each extra time a person touches Unity or the project counts as an "assist"**, and the QA report logs every one.

## Pass criteria (the core POC; all must pass)

| # | Criterion | Evidence qa-lead checks |
|---|---|---|
| P1 | The project was created by the CLI with the agent bridge (`unity projects create ... --with-pipeline`) on 6000.6.4f1 with URP | Command log; `ProjectSettings/ProjectVersion.txt`; `unity status` shows the editor connected |
| P2 | One scene, `Assets/Scenes/World.unity`, is scene 0 in Build Settings. It opens straight into gameplay with **no menus, HUD, inventory or splash screens beyond Unity's own** | Build settings; scene contents list |
| P3 | Terrain of at least 500 m × 500 m with visible height variation (Δheight ≥ 20 m) and at least 3 ambientCG terrain layers painted | `eval` output: terrain size, min/max height, layer count |
| P4 | At least 3 distinct tree types and at least 2 rock or bush types from the MegaKit placed on the terrain. Total trees ≥ 200. Grass details are painted | `eval` output: tree prototype count, instance count, detail layer count |
| P5 | Every vendor material renders in URP. No magenta or error shaders | `eval`: list materials whose shader isn't URP. Must be empty |
| P6 | WASD moves the player, the mouse looks around, gravity applies, and the player can't fall through the terrain | **PlayMode test passes** (P7) |
| P7 | `unity test --mode PlayMode` passes these tests: (a) loads World; (b) simulated W for 2 s moves the player ≥ 3 m horizontally; (c) the player is grounded after 3 s; (d) the frame count advances, so Play mode isn't frozen | NUnit XML with 0 failures |
| P8 | A Windows build (`unity build`) launches into the world | Build exit code 0; the exe exists. **Noah does a 60-second walk-around** as the final sign-off |
| P9 | Zero compile errors and zero errors in the console during the test run | `unity logs` / test log |

**Stretch goal (doesn't affect PASS):** S1 at least 3 animal types wander using NavMesh with walk animations playing. S2 trees sway in the wind.

## Automatic FAIL (stop and report)

- Any Asset Store package, third-party MCP, or file in `Assets/` edited by a person.
- The same blocker goes 3 attempts with no progress (for example Safe Mode, a hung `eval`, a domain-reload loop). **Report the blocker. Don't work around it.**
- More than 3 assists.

## What the pod hands back

1. A verdict from the qa-lead agent: **PASS**, **PASS WITH ASSISTS (n)**, or **FAIL**, with evidence for P1–P9.
2. A **friction log**: every CLI failure, retry, workaround, and how long it took. **This is the real deliverable.** It tells us whether to build Washed Ashore this way.
3. A short note from technical-director on whether this pipeline would scale to the real game.

## Pod

Run `/studio-pod` from `C:\Tools\ruflo\studio`, with the project path set to `E:\GitHub\washed-ashore`. Game-director's greenlight isn't needed because John is making the call for this spike.
