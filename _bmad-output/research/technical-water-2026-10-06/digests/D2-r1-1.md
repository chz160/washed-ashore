## Answers
**Q1 Compatibility Mode.** Deprecated in 6.0; removed in 6.3 (stripped; temporary define to restore, conversion only); fully removed incl. the define in 6.4. On 6000.6 / URP 17.6, a ScriptableRenderPass that only overrides Execute() will not run. Packages using Execute / old ScriptableRendererFeature (BoatAttack planar reflection, Crest URP) must be ported to RecordRenderGraph, or be a version already ported. I did NOT retrieve evidence on BoatAttack's or Crest's current Render Graph status (unverified; see Leads). Consequence: either avoid custom passes (opaque/depth textures + probe/cubemap reflection) or write fresh RecordRenderGraph code.

**Q2 Depth/Opaque textures on WebGL2.** Not conclusively evidenced. Found: Render Graph unsets global textures after execution (custom passes use frame data; ordinary material sampling is the normal path); Depth Texture Mode matters (inference, medium: water in the transparent queue needs depth copied After Opaques). FetchSceneDepth is DX12/Vulkan only, so unavailable on WebGL2. Depth priming is irrelevant to water and unsupported with MSAA/deferred. No primary source found on WebGL2 copy cost, MSAA interaction, or opaque-texture downsampling. Unverified belief: depth copy under MSAA needs a resolve and costs extra bandwidth.

**Q3 SSR.** No shipping built-in URP SSR in evidence. Unity previews one targeted for 6.7, only in alpha builds 6000.6.0a7+. Thread is silent on WebGL2 and transparent surfaces; screen-space marching of colour+depth implies (inference) opaque-content reflection only, and low-res upscaling looks poor on water. Not usable on a stable 6000.6 project. Free options: EricHu33/URP_SSR, jiaozi158/UnitySSReflectionURP, mseonKim, JoshuaLim007 (checked only via search summaries; WebGL2 viability unknown). Safer baseline: reflection probe/cubemap or planar reflection.

**Q4 WebGPU.** Experimental from 6.1; out of experimental in 6000.6 (announced 2026-08-24); opt-in, with compatibility-mode fallback. Browser matrix: only a Dec-2024 list (Chrome/Edge Windows, Chrome macOS/Android) retrieved; discussion defers to caniuse. Shader Graph transparent + depth/opaque texture on WebGPU: no source found. WebGPU enables GPU Resident Drawer, which WebGL2 lacks.

**Q5 Shader Graph on WebGL2.** Evidence only: derivatives fragment-only; vertex sampling needs LOD node; WebGL2 is GLES3-class, no compute, Forward+ loop failure. Not found: sampler limits, half precision behaviour, _CameraDepthTexture sampling in transparent pass on WebGL2, SRP Batcher on WebGL2 (believed OK, unverified).

**Q6 Transparent + GRD/fog.** Only the ShaderGraph bounds bug with GRD (fixed 6000.0.52 / 6000.1.16 / 6000.2.0) and a forum report that GRD breaks skybox ambient. Nothing on transparent + fog.
