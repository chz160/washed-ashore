## Answers
1. **Licence**: "Unity Companion License for Unity-dependent projects" (UCL). UCL s.1 limits use to content authored or distributed under a valid Unity Engine License, so in effect Unity projects only (fine here). **Passes**: four ScriptableRenderPass classes, all with both Execute and RecordRenderGraph (dual path, version-defined from 2023.3). package.json targets URP 12.1, but a RenderGraph change (#15, 2023) landed; I did not compile it on 6000.6/URP 17.6, so Unity 6 compatibility is unverified (issue #25 reports a shader compile error on 6000.0.31f1, Metal, DirectBDRF signature). **Compute shaders**: none; a ComputeBuffer StructuredBuffer holds wave data only and is disabled on WebGL (vector-array fallback). **Planar reflection optional**: yes; enum has Cubemap, ReflectionProbe, PlanarReflection (default), SSR. Issues: only #25 mentions Unity 6; none mention URP 17 or WebGL in the title.
2. **CPU height query**: direct evaluation at the query xz, no inversion of the horizontal displacement. The result is the displaced position of the surface point whose rest position is the sample xz, not the height at that world xz. With peak qi = 2/(A*w*N) horizontal shift can be large, so this height is inconsistent with the rendered surface at that x,z; an inversion/iteration step must be added if exact height at (x,z) is required. Time: `Time.time` (`Time.realtimeSinceStartup` in edit mode), float. The shader's time source was not read this run.
3. **Unity templates**: the URP 3D Sample is a Unity Hub template (no Asset Store login stated; "Download template" button). Oasis uses Shader Graph water, but I could not get a feature list for the Oasis water (depth fade, refraction, reflection unconfirmed for Oasis). The separate Shader Graph Production Ready sample documents water with reflection, refraction, scrolling normals, depth fog and a Gerstner foam variant. A licence for either sample was not found in what I read; do not assume UCL. Unity 6 status of the URP 3D Sample was "planned" in 2023; current state not verified.
4. **UCL**: commercial use is allowed (royalty-free; games made with the Work are not derivative works and you keep rights in them). The text I read does not forbid a private repo; distribution is permitted, not required. Obligations: use must be tied to a valid Unity Engine License; keep licence and copyright notice; modifications to the Work itself are assigned to Unity (you keep the right to use them); no competing product. This is my reading of the text, not legal advice.
